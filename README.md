# Kivara Healthcare

Mobile-first healthcare shift marketplace connecting facilities with licensed professionals.

## Run locally

```bash
npm install
npm run dev -- --port 4317 --hostname 0.0.0.0
```

Open [http://127.0.0.1:4317](http://127.0.0.1:4317).

## Stack

- Next.js + TypeScript + Tailwind
- Firebase Auth, Firestore, Storage

## Product direction

Kivara is building toward an on-demand shift marketplace experience: post shifts, request work, verify credentials, message, bill facilities, and pay professionals — with a phone-first interface.
