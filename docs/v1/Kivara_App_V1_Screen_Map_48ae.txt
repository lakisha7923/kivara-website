3. Confirmed Assignment Screen Rule
The CNA sees: CONFIRMED — YOU ARE SCHEDULED TO WORK. The facility sees: CONFIRMED ASSIGNMENT. The admin action is: CONFIRM ASSIGNMENT. There is no casual Cancel CNA button. A documented exception workflow is required.
4. Screen Count for Version 1
CNA App: approximately 16 primary screens, plus states/modals.
Facility Portal: approximately 12 primary screens, plus request and review states.
Admin Portal: approximately 24 primary screens, plus record details and exception states.
Estimated Version 1 total: about 52 primary screens before detailed design states.

--- TABLE 1 ---
Trigger | What Happens Next
Facility submits staffing request | Admin receives request and reviews it.
Admin publishes eligible positions | Qualified CNAs can see the shift.
CNA requests shift | Admin receives the request with eligibility checks.
Admin confirms assignment | CNA schedule locks; facility sees assigned CNA; both are notified.
CNA clocks in/out | Admin sees attendance and exceptions; facility sees operational status only.
Timesheet is submitted | Facility reviews; Kivara gives final approval and locks hours.
Hours are locked | Payroll-ready record and facility invoice draft are created from the same approved hours.
